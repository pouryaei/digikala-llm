# شیوه‌نامهٔ برچسب‌گذاری و بازبینی انسانی

در ارزیابی حاضر از API مدل زبانی به‌عنوان داور استفاده نشده است. ChatGPT هنگام ساخت گزارش ابتدا همهٔ نظرهای خام ۱۴ محصول انتخاب‌شده را خواند و ۲۷۵ زوج پرسش-نظر را با سه سطح ۰/۱/۲ برچسب‌گذاری کرد؛ بعد از اجرای سیستم، پاسخ‌ها و نقل‌قول‌های خروجی را موردبه‌مورد با همین مرجع مقایسه کرد. این داوری دستیار، ارزیابی انسانی مستقل یا معیار بی‌خطا محسوب نمی‌شود. برچسب‌های مرجع قبل از اجرای اولیهٔ این ۲۹ پرسش ثبت شدند؛ چند نمونهٔ بخش کنارگذاشته‌شده پس از اجرای اولیه دیده شدند، بنابراین آن بخش یک آزمون کاملاً دست‌نخوردهٔ آینده‌نگر نیست.

## دستور یکسان داوری (قابل استفاده برای داور انسانی یا LLM-as-a-Judge آینده)

```text
نقش: ارزیاب بی‌طرف سیستم پرسش‌وپاسخ درباره نظرات محصولات.
ورودی: شناسه و عنوان محصول، پرسش کاربر، تمامی نظرهای مرجع همان محصول،
یادداشت مرجع مستقل، پاسخ واقعی سیستم و فهرست نقل‌قول‌ها به همراه شناسه نظر.
به هیچ دانشی خارج از این منبع تکیه نکن. درباره ویژگی محصول از نقل دیدگاه
کاربر نتیجه قطعی نگیر. هر معیار را مستقل از بقیه بررسی کن.

کیفیت پاسخ: 2 = نیاز اصلی و جنبه‌های مهم را مفید و مرتبط پوشش می‌دهد
(یا نبود شواهد را درست اعلام می‌کند)؛ 1 = پاسخ جزئی، دارای مطالب نامرتبط
یا بی‌توجه به یکی از جنبه‌ها؛ 0 = نیاز کاربر برآورده نشده / پاسخ نادرست.
Grounding معنایی: 2 = ادعاهای مهم و محدودیت‌ها با منبع ارائه‌شده سازگارند؛
1 = نقل قول واقعی است اما تفسیر موضوع/جهت احساس/دامنه ضعیف یا گمراه‌کننده است؛
0 = ادعای مهم فاقد پشتیبانی است.
ارتباط هر نقل‌قول: 2 = مستقیماً دست‌کم یکی از جنبه‌های سؤال؛
1 = زمینه مرتبط یا ناقص؛ 0 = نامرتبط با سؤال مشخص.
تمایز «نظر کامل مرتبط» و «نقل‌قول مرتبط» را رعایت کن؛ ممکن است بخش اشتباه
یک نظر مرتبط انتخاب شده باشد. زمان/هزینه و کامل بودن شواهد را از حقیقت
ادعا جدا کن. دلیل کوتاه با شناسه منبع ثبت کن.
خروجی ساختاریافته: quality_score، grounding_score، evidence_grades
(شناسه هر نظر و grade)، rationale. اگر شواهد یا مرجع کافی نیست قید کن.
```

این دستور معیار و شیوه‌نامهٔ مورد استفاده در تدوین برچسب‌ها را ثبت می‌کند؛ در این تحویل اجرای خودکار این Prompt با یک مدل/درگاه مستقل صورت نگرفته و هزینهٔ داور API صفر است. نسخهٔ برچسب‌ها فقط برای پاسخ با همان `fingerprint` قابل استفاده است. اگر پاسخ تغییر کند، اسکریپت آن را بدون داوری گزارش می‌کند تا نمرهٔ قدیمی به خروجی جدید منتسب نشود.

## بازبینی انسانی

فایل `results/final/human_review_template.csv` شامل پرسش، پاسخ واقعی، شناسهٔ شواهد، یادداشت مرجع و ستون‌های خالی نمره انسانی است. برای جلوگیری از اثر همرنگی، داور ابتدا ستون‌های نمرهٔ دستیار را مخفی کند؛ پس از مطالعهٔ منبع، ۰/۱/۲ و دلیل را بنویسد. اگر دو نفر داوری می‌کنند، هر یک نسخهٔ جدا پر کنند. سپس نسخهٔ تکمیل‌شده را مقایسه کنید:

```powershell
python evaluation/compare_human.py evaluation/results/final/human_review_template.csv
```

نتیجه شامل تعداد داوری، Exact Agreement و Quadratic Weighted Cohen's Kappa است. خانه‌های خالی صفر محسوب نمی‌شوند. اکنون هیچ نمرهٔ انسانی در فایل وارد نشده، پس توافق انسانی ادعا نمی‌شود.
